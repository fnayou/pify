# pify

[![Pify banner: a red pi, f and y mark on a dark tile beside the name Pify, the tagline "One Pi. Your models. Your tools. Your workflow." and a note that Pify has no released distribution or features.](brand/generated/readme-banner.svg)](brand/generated/readme-banner.svg)

**One Pi. Your models. Your tools. Your workflow.**

Pify is a planned ready-to-use distribution of configuration, skills, tools, and workflows for the official Pi coding agent. The goal is a portable, model-agnostic setup that builds on Pi rather than replacing it.

**Status:** Pify is in bootstrap. This repository has a private Pi development package and tests, but no supported release or installable distribution.

## Implemented in the repository (unreleased)

- A [private Pi package](package.json) with extensions, bundled skills, a theme, and test fixtures. Its version is development metadata, not a release.
- Reproducible [brand sources](brand/src/) and generated assets, checked by CI.
- The MIT [license](LICENSE), [contribution guidance](CONTRIBUTING.md), [code of conduct](CODE_OF_CONDUCT.md), and [security policy](SECURITY.md).

## Planned distribution

The ready-to-use Pify distribution and public setup instructions remain planned. [GitHub Issues](https://github.com/fnayou/pify/issues) track the roadmap; an issue is not a shipped capability.

Public branding uses Catppuccin Macchiato Red (`#ed8796`).
