# Minimal bundled skills

Pify is still a bootstrap project. This private package declares three skills for Pi 1.5.2: the MVP skills `pify-debug` and `pify-test-first`, plus the Wave 3 `pify-handoff` skill. They are adapted, self-contained instructions from the pinned `mattpocock/skills` source recorded in `skills/catalog.json` and in each skill's frontmatter. The upstream MIT notice is in `skills/LICENSE.mattpocock`. No scripts, external integrations, or install-time commands are bundled.

Pi loads them from the package through `package.json`'s `pi.skills` list. Pify does not copy them into a user's skill directory. Existing user skill files are never replaced. If a user skill shares a name, Pi's first-discovered rule chooses one and emits a collision warning; the package does not promise precedence. `/pify-health` shows bundled source and commit revision when Pi settings declare this package. The package's private version is separate from the pinned upstream revision.

`/skill:pify-handoff` asks Pi's agent to write a private Markdown snapshot under the operating system's temporary directory. It records task state, blockers, next steps, and references; it must redact sensitive values and read the file back before returning its path. It does not copy a session transcript, load as memory, or replace native session resume. Redaction is an agent review step, not a deterministic guarantee for an unknown secret; the agent must stop if it cannot verify the note is safe.
