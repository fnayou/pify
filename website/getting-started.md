# Getting started

Pify has no released software or public install command. Setup instructions will follow a validated release.

Contributors can inspect the private development package in the [GitHub repository](https://github.com/fnayou/pify). Follow the [contribution guide](https://github.com/fnayou/pify/blob/main/CONTRIBUTING.md) to run repository checks. These checks validate source work, not a released installation.

For planned features or questions, use [GitHub Issues](https://github.com/fnayou/pify/issues).
