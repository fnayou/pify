# Getting started

Pify has no released software to install, so there is no install command yet. Setup instructions will follow a validated release.

For the current project status, visit the [GitHub repository](https://github.com/fnayou/pify). To discuss future plans or ask a question, use [GitHub Issues](https://github.com/fnayou/pify/issues).
