# Security Policy

Pify has no supported release or installable software yet. No versions currently receive security updates.

## Report a vulnerability

Do not post exploit details, credentials, or sensitive data in a public issue. Open a public issue titled `Request private security contact` with **no vulnerability details**. A maintainer can then arrange a private reporting channel. If GitHub's private vulnerability reporting becomes available, its Security tab may offer a direct route; do not assume it is enabled.

Include affected files or versions, impact, reproduction steps, and a possible fix only after a private channel is agreed. Maintainers will acknowledge the report, assess its scope, and coordinate a fix and disclosure with the reporter. For a vulnerability in Pi itself, report it to the Pi maintainers through their security guidance.
